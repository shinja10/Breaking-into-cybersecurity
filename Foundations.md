# 01-Foundations – Cybersecurity Basics

> This section covers the absolute fundamentals required to start a career in cybersecurity.  
> If you build a strong base here, advanced security concepts become much easier later.

---

## 🌐 1. Networking Basics

Networking knowledge is essential for understanding how attacks and defenses work.

### Key Topics
- OSI Model & TCP/IP
- IPv4, IPv6, Subnetting
- Routing & Switching
- Common Protocols: HTTP/HTTPS, DNS, FTP, SSH, SMTP
- Firewalls, Proxies, VPNs

### Learning Resources
- Cisco Networking Basics  
  https://www.cisco.com/c/en/us/training-events/training-certifications/training.html

- NetworkChuck (YouTube)  
  https://www.youtube.com/c/NetworkChuck

- TryHackMe – Networking Fundamentals  
  https://tryhackme.com/room/networkingfundamentals

---

## 💻 2. Operating Systems Fundamentals

A cybersecurity professional must be comfortable with both Linux and Windows.

### Linux
- File system structure
- Basic commands
- Users & permissions
- Processes & services

### Windows
- Command Prompt & PowerShell
- Event Viewer
- Registry basics
- Services & scheduled tasks

### Practice Platforms
- Linux Journey  
  https://linuxjourney.com/

- OverTheWire – Bandit (Linux Practice)  
  https://overthewire.org/wargames/bandit/

---

## 🌍 3. Web & Application Basics

Before learning web hacking, you must understand how web apps work.

### Core Concepts
- How HTTP requests and responses work
- Cookies & sessions
- Client-side vs server-side
- Databases and SQL basics
- Authentication & authorization

### Learning Resources
- W3Schools – SQL Basics  
  https://www.w3schools.com/sql/

- OWASP Top 10  
  https://owasp.org/www-project-top-ten/

---

## 🧪 4. Hands-On Learning Platforms (Very Important)

Theory alone is not enough. These platforms help you **learn by doing**.

### 🧃 OWASP Juice Shop
A deliberately vulnerable web application to practice real-world vulnerabilities.

- GitHub: https://github.com/juice-shop/juice-shop  
- Documentation: https://owasp.org/www-project-juice-shop/

Use Juice Shop to practice:
- SQL Injection
- XSS
- Authentication issues
- Business logic flaws

---

### 🕷️ PortSwigger Web Security Academy
One of the **best free platforms** for learning web security.

- https://portswigger.net/web-security

Covers:
- SQL Injection
- XSS
- CSRF
- Authentication & session issues
- API security
- Business logic vulnerabilities

Highly recommended for **web application security beginners**.

---

### 🔓 TryHackMe
Beginner-friendly platform with guided learning paths.

- https://tryhackme.com/

Recommended paths:
- Pre Security
- Jr Penetration Tester
- Web Fundamentals

---

### 💀 Hack The Box
More advanced, realistic labs for penetration testing.

- https://www.hackthebox.com/

Best used **after** TryHackMe basics.

---

### 🧨 VulnHub
Downloadable vulnerable virtual machines for offline practice.

- https://www.vulnhub.com/

Great for:
- Building a home lab
- Practicing exploitation
- Learning real-world attack chains

---

## 🔐 5. Core Security Concepts

You should understand these before moving forward:

- CIA Triad (Confidentiality, Integrity, Availability)
- Authentication vs Authorization
- Encryption basics (symmetric & asymmetric)
- Hashing
- Malware types (virus, worm, trojan, ransomware)
- Common misconfigurations

---

## 🧰 6. Suggested Beginner Setup

1. Install **VirtualBox or VMware**
2. Create:
   - One Linux VM (Kali or Ubuntu)
   - One Windows VM
3. Install:
   - Burp Suite Community
   - Wireshark
4. Practice labs on:
   - TryHackMe
   - PortSwigger
   - OWASP Juice Shop

---

## 📌 Final Advice

Do not rush this phase.  
Strong foundations separate **good cybersecurity professionals from average ones**.

Once comfortable with these topics, move to:
- Web application security
- Network security
- Penetration testing
- Blue team and SOC concepts

Happy Learning 🚀
